# rick-masterson.github.io

Small HTML, CSS and JavaScript projects from my 2016 Interapt internship with TEKY at Big Sandy Community and Technical College's Paintsville campus in Eastern Kentucky, cleaned up in 2026.

- `guessing-game/`: guess three different digits in ten tries.
- `weatherly/`: weather cards for any city or zip code (Open-Meteo, no API key).
- `maply/`: map cards for any city or zip code (Leaflet and OpenStreetMap, no API key).
- `storeApp/`: a responsive storefront layout in HTML and CSS.
- `assets/site.css`: the shared theme for the portfolio pages.
- `files/fixit.js`: a debugging exercise; run it with `node files/fixit.js`.

Everything is static: open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
